# Архитектура

## Схема

┌──────────────────┐        ┌──────────────────┐        ┌──────────────────┐
│  Vue-клиент      │  HTTP  │  ASP.NET Core    │  SQL   │  PostgreSQL      │
│  порт 5173       │ ─────► │  порт 5000       │ ─────► │  порт 5432       │
│  рисует экраны   │        │  проверяет       │        │  хранит данные   │
│  шлёт запросы    │        │  правила         │        │                  │
└──────────────────┘        └──────────────────┘        └──────────────────┘

Vue :5173  →  ASP.NET Core :5000  →  PostgreSQL :5432

## Пояснение

Три узла, две связи, один источник правды об инцидентах.

- **Vue-клиент (5173)** — рисует экран, отправляет HTTP-запросы.
- **ASP.NET Core (5000)** — проверяет правила, отвечает.
- **PostgreSQL (5432)** — хранит строки.

Браузер не пишет в PostgreSQL напрямую, потому что все правила
и проверки живут на сервере. Прямой стрелки «браузер → база» нет.
