# Матрица ролей

| Действие                 | Диспетчер | Инженер   | Гость (не вошел) |
| :----------------------- | :-------- | :-------- | :--------------- |
| POST создать инцидент    | да (201)  | нет (403) | нет (401)        |
| PATCH .../assignee       | да (200)  | нет (403) | нет (401)        |
| PATCH .../status (свой)  | да (200)  | да (200)  | нет (401)        |
| PATCH .../status (чужой) | да (200)  | нет (403) | нет (401)        |
| GET список               | да (200)  | да (200)  | нет (401)        |

*Примечание: Пароли в БД хранятся в виде хеша.*
