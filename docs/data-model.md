# Модель данных

## Словарь проекта

| Термин курса | Термин моей темы |
|--------------|------------------|
| Ticket       | Инцидент         |
| Site         | Категория        |
| User         | Сотрудник        |

## Сущности

### Incident (Инцидент) — главный объект

| Поле            | Тип      | Ключ | Описание                          |
|-----------------|----------|------|-----------------------------------|
| id              | int      | PK   | машинный ключ                     |
| number          | string   |      | человеческий номер, «INC-2026-001»|
| title           | string   |      | краткое название                  |
| description     | string   |      | описание                          |
| status          | string   |      | New / InProgress / Closed / Cancelled |
| probability     | string   |      | Low / Medium / High               |
| consequence     | string   |      | последствие                       |
| categoryId      | int      | FK   | → Category.id                     |
| createdByUserId | int      | FK   | → Employee.id                     |
| assigneeUserId  | int      | FK   | → Employee.id, может быть NULL    |

### Category (Категория) — справочник

| Поле | Тип    | Ключ | Описание           |
|------|--------|------|--------------------|
| id   | int    | PK   | машинный ключ      |
| name | string |      | название категории |

### Employee (Сотрудник) — пользователь

| Поле | Тип    | Ключ | Описание       |
|------|--------|------|----------------|
| id   | int    | PK   | машинный ключ  |
| name | string |      | имя или логин  |

## ER-диаграмма

Category 1 ──── N Incident
Employee 1 ──── N Incident (createdByUserId)
Employee 0..1 ── N Incident (assigneeUserId)

## Связи словами

- Одна категория — много инцидентов.
- Один сотрудник создаёт много инцидентов.
- Один сотрудник может быть назначен на много инцидентов.
- У нового инцидента ответственный может отсутствовать.

## Проверка ЗНФ

Название категории хранится в сущности Category один раз.
Инцидент содержит внешний ключ categoryId. При переименовании
категории меняется одна строка, поэтому текст названия
не дублируется в инцидентах.
