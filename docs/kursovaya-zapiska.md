# Курсовая записка

## 1. Анализ и требования
Система предназначена для управления инцидентами в организации. Роли: Диспетчер, Инженер. Требования описаны в `lab-01-requirements.md`.

## 2. Проектирование и архитектура
Архитектура: Vue (:5173) → ASP.NET Core (:5000) → PostgreSQL (:5432). Это архитектура web-ИС семестра.
Сущности: Incident, Employee, Category.

## 3. Клиентская часть (UI)
Реализована на Vue 3 + Vite. Есть экраны: Список инцидентов, Создание инцидента.

## 4. Сервер и API
Реализован REST API с кодами 200, 201, 400, 401, 403, 404, 409. Используются два PATCH-запроса (для назначения и смены статуса).

## 5. База данных
Используется PostgreSQL и Entity Framework Core (миграции лежат в `backend/Migrations`).

## 6. Безопасность
JWT-авторизация. Пароли захешированы. Права проверяются на сервере (401 и 403).

## 7. Поставка
Инструкция по запуску находится в корневом `README.md`.
