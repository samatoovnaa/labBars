# Список известных дефектов

1. **Нет формы авторизации на сайте.** При открытии сайта токен получается автоматически под тестовым пользователем (диспетчером) для упрощения демонстрации. Полноценная страница входа (логин/пароль) не реализована.
2. **Управление только через API (Swagger).** В таблице на сайте пока нет кнопок для назначения исполнителя и смены статуса инцидента. Эти действия работают через Swagger.
3. **Отсутствие уведомлений.** При создании инцидента нет всплывающих уведомлений об успехе или ошибке (просто происходит переход к списку).
