# Отчет по ЛР11. Вход и права

## 1. Цель
Реализовать JWT-авторизацию и разграничение прав доступа (роли Диспетчер и Инженер). Проверить коды ответов 401 (не авторизован) и 403 (нет прав). Защитить пароли с помощью хеширования и проверить защиту от XSS-атак во Vue.

## 2. Что сделали
1. Установили пакет `Microsoft.AspNetCore.Authentication.JwtBearer`.
2. Добавили поля `Username`, `PasswordHash`, `Role` в модель `Employee`.
3. Создали `AuthController` с методами регистрации (`register`) и входа (`login`).
4. Для хеширования паролей использовали `PasswordHasher` из ASP.NET Core Identity.
5. Настроили проверку JWT-токенов в `Program.cs`.
6. Закрыли методы `IncidentsController` атрибутами `[Authorize]`.
7. Добавили проверку: Инженер может менять статус только тех инцидентов, которые назначены на него.
8. Проверили, что Vue безопасно выводит текст (без `v-html`), предотвращая XSS.
